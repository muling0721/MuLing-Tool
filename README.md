MuLingTool

一站式 Android 多媒体工具箱

MuLingTool 是一款面向 Android 平台的多功能媒体工具应用，整合音乐搜索、视频解析、音频处理与文件解密等实用功能，致力于为用户提供便捷、统一的多媒体处理体验。

✨ 功能介绍

🎵 音乐功能

- 网易云音乐歌曲与歌手搜索
- 多种音质选择，支持在线播放与试听
- 歌曲下载与歌词获取
- 歌词同步保存，支持原文与翻译

🎬 视频功能

- 哔哩哔哩视频解析与播放
- 抖音、快手短视频解析
- 支持无水印视频获取与下载
- 支持视频分 P 信息及播放地址获取
- 支持图集解析与批量下载

🎧 音频处理

- 支持 MP3、WAV、AAC、FLAC、OGG、M4A、OPUS、WMA 等格式转换
- 支持自定义输出码率

📦 文件解密

- 支持 NCM 文件单个及批量解密
- 自动识别输出音频格式
- 自动写入歌曲信息与专辑封面
- 自动获取并保存对应歌词

📥 下载管理

- 统一记录下载历史
- 支持查看文件、复制路径与删除记录
- 自动识别下载文件类型

💙 项目理念

MuLingTool 希望将日常使用频率较高的多媒体工具整合到一个应用中，减少不同工具之间的切换，让音乐、视频与音频文件的处理更加简单方便。

MuLingTool —— 让多媒体工具触手可及。
